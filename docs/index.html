Pattern reference
Direction labels: O = wire itself, ±X/Y/Z = neighbours.
Small-coord patterns are the common ones, dominating ordinary build areas.
Large-coord patterns need the h ^ (h >>> 16) spread to actually bite, i.e. some member of the 7-position set reaching |hashCode| ≥ 65536.
Because the order depends only on h = x + 31y + 961z, and one step in Z shifts h by 961, every pattern — including the rare ones — is reachable within a few hundred blocks of spawn. All example coords below are given at y = 0, within |x| ≤ 418 and |z| ≤ 546.
