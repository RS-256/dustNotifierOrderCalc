Pattern reference
Direction labels: O = wire itself, ±X/Y/Z = neighbours.
Small-coord patterns are the common ones, dominating ordinary build areas.
Large-coord patterns need the h ^ (h >>> 16) spread to actually bite, i.e. some member of the 7-position set reaching |hashCode| ≥ 65536.
Because the order depends only on h = x + 31y + 961z, and one step in Z shifts h by 961, every pattern — including the rare ones — is reachable within a few hundred blocks of spawn. All example coords below are given at y = 0, within |x| ≤ 418 and |z| ≤ 546.
Probabilities are exact, not sampled. A bucket is (h & 15) ^ ((h >>> 16) & 15), so it depends only on bits 0–3 and 16–19 of h — i.e. on h mod 220. All 7 offsets shift h by a constant, so the whole update order is a function of h mod 220 alone: the pattern is periodic with 1,048,576 blocks per period. Exhaustively enumerating that single period gives each order's exact count, shown as a fraction under the percentage (hover for the reduced form). The 60 counts sum to exactly 220, and match Earthcomputer's 232 brute force exactly — every count there is 4096× the count here.
